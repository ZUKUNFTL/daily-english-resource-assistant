# 使用说明

## 基本流程

1. 在“资源搜索”粘贴 YouTube、B 站或视频号链接，也可以按标题搜索资源。
2. 只下载自己拥有或已获得授权的公开媒体；也可以直接导入本地 MP4、MP3、WAV 或 SRT。
3. 在“导入任务”选择本地媒体后，标题会默认使用媒体文件名（不含扩展名），仍可手动修改；再选择源语言、目标语言和 Whisper 模型，可选 TXT、DOCX 或可提取文字的 PDF 作为参考文稿，建立项目后点击“加入处理队列”。
4. 在“任务中心”查看模型下载、转写和翻译进度。
5. 在“字幕预览”检查原文、译文和时间码，再后台导出素材包。勾选“导出完成后打开文件夹”可自动打开本次生成的目录。

## 任务取消与恢复

在“任务中心”选择任务后点击“取消所选任务”。正在执行的任务会在当前安全步骤结束后停止。软件异常退出时，遗留的“处理中”项目会在下次启动时标记为失败并提示可重试；双击资料库中的失败或已取消项目会返回导入页。

## 模型管理

“模型管理”页显示 `small`、`medium` 和 `large-v3` 是否已经缓存及其磁盘占用。安装版已内置 `small` 和 `medium`；`large-v3` 只在首次使用或主动下载时联网，缓存存在时直接本地加载。删除模型后，下次使用该模型需要重新下载。

## 参考文稿

参考文稿会提取文字并作为 Whisper 的识别提示，主要用于改善专有名词、人物名和固定表达。使用参考文稿时程序选择支持提示词的 faster-whisper 路径；参考文本不会直接替换识别结果。

## 输出内容

每个导出目录包含：

- `标题.mp3`
- `标题_中英双语.srt`
- `source.url.txt`
- `metadata.json`
- 可选 ZIP 归档

中文输入默认生成“中文原文在前、英文译文在后”；英语输入顺序相反。

## 并发设置

下载任务可以并行运行。字幕任务默认一次运行 1 个，适合 `medium` 和 `large-v3`；内存或显存充足时可在“任务中心”将最大并发转写任务改为 2。两个大模型并行会显著增加内存占用。

## 平台限制

- YouTube API Key 只用于搜索和元数据，不代表媒体下载授权。
- B 站和 YouTube 下载遵循平台限制，不读取浏览器 Cookie，不处理会员、私有、登录或 DRM 内容。
- 视频号只在微信匿名官方响应直接提供媒体流时下载；否则请通过官方方式保存或向作者取得原文件。
- 软件不会提取登录会话、安装代理证书或绕过访问控制。

## 本地数据

资料库、设置、下载、模型、缓存和临时文件都位于项目目录的 `data`、`resources`、`work` 与 `engine` 子目录。这些目录默认不进入 Git。
