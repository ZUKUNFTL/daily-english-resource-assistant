# 使用说明

## 基本流程

1. 在“资源搜索”粘贴 YouTube、B 站或视频号链接，也可以按标题搜索资源。
2. 只下载自己拥有或已获得授权的公开媒体；也可以直接导入本地 MP4、MP3、WAV 或 SRT。
3. 在“导入任务”选择源语言、目标语言和 Whisper 模型，建立项目后点击“加入处理队列”。
4. 在“任务中心”查看模型下载、转写和翻译进度。
5. 在“字幕预览”检查原文、译文和时间码，再导出素材包。

## 输出内容

每个导出目录包含：

- `标题.mp3`
- `标题_中英双语.srt`
- `source.url.txt`
- `metadata.json`
- 可选 ZIP 归档

中文输入默认生成“中文原文在前、英文译文在后”；英语输入顺序相反。

## 并发设置

下载任务可以并行运行。字幕任务默认一次运行 1 个，适合 `medium` 和 `large-v3`；内存或显存充足时可在“任务中心”将最大并发转写任务改为 2。两个大模型并行会显著增加内存占用。

## 平台限制

- YouTube API Key 只用于搜索和元数据，不代表媒体下载授权。
- B 站和 YouTube 下载遵循平台限制，不读取浏览器 Cookie，不处理会员、私有、登录或 DRM 内容。
- 视频号只在微信匿名官方响应直接提供媒体流时下载；否则请通过官方方式保存或向作者取得原文件。
- 软件不会提取登录会话、安装代理证书或绕过访问控制。

## 本地数据

资料库、设置、下载、模型、缓存和临时文件都位于项目目录的 `data`、`resources`、`work` 与 `engine` 子目录。这些目录默认不进入 Git。
